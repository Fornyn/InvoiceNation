# InvoiceNation Backend Engine (v1)

InvoiceNation is an open-source, offline-first invoice engine for small businesses in India.

This repository contains:
- Invoice data models
- GST-compliant invoice calculations
- Professional A4 PDF generation (ReportLab)
- SQLite-based local storage

This backend is designed to be embedded into:
- Desktop applications (Electron)
- Mobile applications (Android WebView)

⚠️ This repository does NOT include a consumer UI.
